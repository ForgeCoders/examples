# JavaScript Counter

## Description

A browser-based counter that increments, decrements, and resets its value. It
uses a single JavaScript state variable and updates the page after every click.

## Run

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Learning Goals

- Selecting DOM elements
- Handling click events
- Updating a value with JavaScript state
